# Reason for keeping membership database on our website

The website has a membership database attached that is a bespoke database created by Cyberry. We have kept this despite also having to maintain a membership database with RSL NSW. Ideally we would transition to a membership contact relationship manager managed and supplied by RSL NSW to avoid inconsistency and the overheads in maintaining our own database.

From Cyberry:

> The main difference from a practical standpoint is that it integrates directly with MailChimp for EDM services so you can send rich format emails. 
>
>There were other considerations at the start which were part of the old system which we built in. That was mainly additional information fields for spouses and family of veterans whose details the sub-branch wanted to retain but I'm unsure if that is getting used. 
>
>There is substantial historical data there from the old system when it was being used though from what I understand - although I haven't investigated this personally.
